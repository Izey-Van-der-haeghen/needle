Privacy policy

Last updated: 22 November 2026

In short

  • Needle has no server of its own. It collects no analytics, shows no ads and sells nothing.
  • It reads a web page only when you open Needle on that page or, if you keep Needle open in the side panel and allow access to websites, when you switch to that tab.
  • What it finds stays in your browser. It sends data to another service only when you start a check that says so.

Who makes Needle

Needle is a free, open-source Chrome extension made by Izey Van der Haeghen, a private developer. Its source code is public on GitHub, so anyone can check what it does. Questions about privacy: hello@izey.dev.

What Needle reads

When you click the Needle button on a tab, or use its keyboard shortcut or right-click menu there, Chrome lets Needle read that tab. Needle then reads, from that page only:

  • the page's address, title, meta tags, headings, links, images, structured data, language tags and text (for word counts, readability, keyword checks and how easy the page is to quote);
  • files on the same website that search engines read: the page's HTML as the server sends it, /robots.txt, the XML sitemap, /llms.txt and /llms-full.txt. These requests are made without your cookies.

To show image previews, Needle loads the page's images and its social preview images (og:image and twitter:image) from the servers that host them, as your browser does when it shows the page. A downloaded HTML report shows the same images, so opening the report loads them again from those servers.

Side panel: if you keep Needle open in the side panel and have allowed access to websites, it audits each tab you switch to, and each new page you open in it, while the panel is open, with the same checks, and adds the page to your history. Close the panel to stop this.

Needle never reads tabs in the background, and it does not read form fields or passwords.

What Needle stores, and where

Everything below stays in Chrome on your device:

  • Audit results, so reopening Needle is instant: kept from 5 minutes to 12 hours depending on the check (the Core Web Vitals trend longest), at most 100 results.
  • History: the last 50 pages you audited (address, title, score, time). Clear it any time in Settings.
  • Snapshots of up to 200 audited pages (title, description, H1, canonical, robots, status, counts), to show what changed since your last audit.
  • Your API credentials for DataForSEO, Google and Bing Webmaster Tools, if you add them. They are stored on this device only and are not synced to your Google account. They leave it only if you include them in a settings file you download yourself.
  • Your last inputs and choices: the tab you had open, what you typed in Compare and Google results, the country and language you picked for each website, and the one-time "Needle was updated" note, so they are still there when you reopen Needle. Clearing the history also clears the countries and languages picked per website.
  • Preferences (theme, default country and language, CSV separator, shortcuts, side panel, image checks). Chrome may sync these with your Google account if you use Chrome sync.

Uninstalling Needle deletes all of it.

What Needle sends, and to whom

Only when you start these checks yourself:

  • Speed test: the page address and your API key go to Google PageSpeed Insights, which loads the page and returns performance scores. Google's privacy policy applies.
  • Core Web Vitals trend: the page address (or its site) and your API key go to Google's Chrome UX Report API, which returns real-user speed data. Google's privacy policy applies.
  • Bing data: the page address, your site's address and your API key go to Microsoft Bing Webmaster Tools, which returns your own search data for that page. Microsoft's privacy statement applies.
  • Keyword lookup and Google results (SERP): the page address, its domain or your search keyword, the chosen country and language, and your DataForSEO login go to DataForSEO, which returns ranking data and bills your own DataForSEO account. DataForSEO's privacy policy applies.
  • Link check, competitor comparison, hreflang alternates, http/https and www versions, and image sizes: Needle requests those web addresses directly from your browser, without your cookies. The websites involved receive an ordinary request, including your IP address, as when you visit them. Needle does not request addresses on your local network (such as your router) that a page points to, unless the audited page is itself on your local network; only a website that redirects there can still lead a request to such an address. These checks need the optional "access to websites" permission, which you can turn off in Settings.

Links to other tools (for example Rich Results Test, Ahrefs or Wayback Machine) open that tool's website in a new tab, with the page address in the link, only when you click them. The same goes for the links to Needle's changelog and source code on GitHub.

Needle's author receives none of this data.

Limited use

The use of information received by Needle complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Needle uses page data only to show you its audit. It passes data on only to the service you start a check with (Google, Microsoft Bing or DataForSEO), and only to run that check. It does not sell data, use it for advertising or to decide on credit, and no person reads it.

Permissions

  • activeTab and scripting: read the tab you open Needle on, and highlight headings or links there when you ask.
  • storage: keep results, history, snapshots for "what changed since the last audit", settings and API credentials on your device.
  • sidePanel and contextMenus: show Needle in the side panel if you choose (where it follows the tab you switch to), and add Needle to the right-click menu.
  • Access to websites (optional, off by default): check links, load competitor pages and hreflang alternates, measure image files, compare the http/https and www versions, let the side panel follow your tabs, and reach the DataForSEO and Bing APIs.

Children

Needle is a tool for website owners and is not aimed at children.
