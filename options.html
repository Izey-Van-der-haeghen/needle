What Needle reads and sends

  • Needle reads a page only when you open it on that page. It has no server and collects no analytics.
  • Results, history and your API keys stay in this browser, on this device.
  • The speed test and the Core Web Vitals trend send the page URL to Google. Keyword and SERP lookups send the URL or keyword to DataForSEO, and Bing data requests send it to Bing Webmaster Tools, each with your own login or key. All of these run only when you click them.
  • With site access on, link checks, competitor pages and image sizes are requested straight from those sites.

Full privacy policy

Site access

Off by default. Needed only to check whether links work, to load competitor pages and to measure images on other servers.

DataForSEO (optional, paid)

Keyword rankings and Google results come from DataForSEO, a pay-per-use data provider, through your own account. A keyword lookup costs about $0.025 and a Google search about $0.004; results are kept for 30 to 60 minutes so a repeat costs nothing. Use your API login and API password from the DataForSEO dashboard.

Where to find your API login and password
  1. Create an account at dataforseo.com. You pay per use from a balance you top up.
  2. Open API Access in the DataForSEO dashboard.
  3. Copy the API login and the API password. The API password is not the password you sign in with.
  4. The API password is hidden 24 hours after you sign up. On the same page, have it sent to your email again.

Stored only on this device, never synced to your Google account.

PageSpeed Insights

Free. Google only answers requests that carry an API key. The same key also gives the Core Web Vitals trend.

Where to find your Google API key
  1. Open Google's PageSpeed Insights guide and click Get a Key. Sign in with a Google account and pick or create a project.
  2. Copy the key, paste it below and click Save.
  3. For the Core Web Vitals trend, open the Chrome UX Report API in the same project and click Enable.
  4. Safer: in Google Cloud under APIs & Services → Credentials, open the key and limit it to these two APIs.

Bing Webmaster Tools (optional, free)

Clicks, impressions, queries and crawl info for your own verified sites in Bing.

Where to find your Bing API key
  1. Sign in to Bing Webmaster Tools and add and verify your site. You can import sites from Google Search Console.
  2. Open Settings (the gear icon), then API Access. Accept the terms the first time.
  3. Click Generate API Key, copy it, paste it below and click Save. One key works for all your verified sites.

Stored only on this device.

Default market

Image checks

Needle always flags images shown larger than their file (blurry), files far larger than shown, and a main image under 1200 px wide (Google's advice for Discover). Add your own rules below.
